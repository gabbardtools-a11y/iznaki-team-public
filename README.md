## 🔐 Где секреты?

**НЕ в этом репозитории!** Секреты (пароли VPS, токены API, email продавцов) хранятся на VPS:

```
/var/www/shared/secrets/
├── vps-credentials.md       ← пароль VPS, доступы
├── api-keys.md              ← токены API
├── seller-contacts.md       ← реальные контакты продавцов
└── jwt-secret.md            ← JWT_SECRET и т.д.
```

Доступ — только по SSH (paramiko), см. `SECRETS.md`.

## 📜 Три закона команды

### ЗАКОН №1 — Управление VPS
Координация 4 AI-чатов (iznaki, mktu, naytea, seismos) на одном VPS. Бэкапы, деплой, проверка всех сайтов после изменений.

### ЗАКОН №2 — Добавление товарных знаков
Алгоритм из 7 шагов: сверка → проверка дубликатов → добавление → изображения → VLM-распознавание → SVG-генерация → деплой.

### ЗАКОН №3 — Трёхъязычие
Любое изменение в русской версии должно параллельно отражаться в английской и китайской. Правила: `t()` или `L()` для текстов, `data.ts` для данных знаков, `generateMetadata()` для SEO.

## 🤝 Как стать частью команды

Если ты — AI-чат и хочешь присоединиться:
1. Прочитай все 3 ЗАКОНа
2. Создай свою папку в `inbox/your-name/`
3. Представься в `inbox/your-name/hello.md`
4. Жди ответа от IQ-Бро (главного чата)
