## 📋 Алгоритм добавления знаков (7 шагов)

### Шаг 1. Сверка
- Прочитать все рег. номера из нового источника (Excel, ФИПС, ptn.su, iqin.ru)
- Сравнить с существующими в `data.ts` (`registrationNumber`)
- Разделить на: **новые** (нет в каталоге) и **дубликаты** (уже есть)

### Шаг 2. Дубликаты — показать пользователю
- Вывести список дубликатов: ID, название, рег. номер, текущий продавец
- Задать вопрос: «Обновить продавца/цену/классы? Или пропустить?»
- **НЕ изменять продавца без подтверждения**

### Шаг 3. Новые знаки — добавить
- ID: следующий после максимального в data.ts
- seller: указанный пользователем (ТОЧНО как сказано — "Иван А." ≠ "Иван")
- FIPS ссылка: `https://www1.fips.ru/fips_servl/fips_servlet?DB=RUTM&rn=1895&DocNumber={рег.номер}`

### Шаг 4. Изображения
- **imageUrl ВСЕГДА**: `/images/trademarks/{рег.номер}.svg` (numeric, НЕ slug!)
- SVG файл: `public/images/trademarks/{рег.номер}.svg`
- JPG файл: `public/images/trademarks/{рег.номер}.jpg` (если есть)
- Источники JPG: Excel (openpyxl), ФИПС, iqin.ru, ptn.su

### Шаг 5. VLM — распознавание названий
- Если есть JPG → запустить VLM (`z-ai vision --thinking`)
- Применить название к: `name` в data.ts, `description`, SVG текст
- Если VLM не распознал → оставить "Знак №{рег.номер}"

### Шаг 6. SVG — генерация
- Размер: 800×800, фон `#1a2240` → `#2a3268` (gradientUnits="userSpaceOnUse")
- Шрифт: `font-weight="400"` (не жирный), `dominant-baseline="central"`, `text-anchor="middle"`
- Размер шрифта: 97px (≤10 символов), 70px (≤20), 50px (>20)
- Первая буква заглавная, остальные строчные (кроме аббревиатур и специальных)

### Шаг 7. Деплой — только после подтверждения
- Показать пользователю: сколько знаков, сколько с названиями, сколько с JPG
- Получить подтверждение
- Деплоить: data.ts + SVG + JPG на VPS
- Проверить: HTTP 200, знаки видны, названия правильные

## ⚠️ КРИТИЧЕСКИЕ ПРАВИЛА

### 1. imageUrl — ТОЛЬКО numeric
```javascript
// ✅ ПРАВИЛЬНО
imageUrl: "/images/trademarks/871696.svg"

// ❌ ЗАПРЕЩЕНО
imageUrl: "/images/trademarks/1254-joymee.svg"
imageUrl: "/images/trademarks/871696.jpg"  // JPG только при галке "Картинки"
```

### 2. Продавец — ТОЧНО как указано
```
"Иван А." ≠ "Иван" ≠ "Иванов Сергей"
"Михаил Петрович" ≠ "Михаил"
"Павел" ≠ "Павел А."
```

### 3. SVG файл — по рег. номеру
```
SVG: public/images/trademarks/{рег.номер}.svg
JPG: public/images/trademarks/{рег.номер}.jpg
```

### 4. Бейджи — по продавцу
| Продавец | Бейджи |
|----------|--------|
| Михаил Петрович | Ракета (+ Best если 7+ классов) |
| Павел (не ТВОРИ/Просто чудо) | Top + Best + Trust + 25% Sale |
| Иван А. | Top + Best |
| Остальные | По стандартной логике |

### 5. Сортировка
1. Михаил Петрович (Ракета)
2. Павел (Top/Best/Trust/Sale)
3. Иван А. (Top/Best)
4. Остальные
5. «ТВОРИ» и «Просто чудо» (другой Павел)
