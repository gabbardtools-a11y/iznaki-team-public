## 📜 Преамбула

После внедрения трёхъязычной системы (RU/EN/ZH) на iznaki.ru пользователь (Бро) постановил: **любое изменение в русской версии сайта должно автоматически отражаться в английской и китайской версиях**. Это правило защищает от рассинхронизации языков и потери доверия иностранных клиентов.

---

## 🌍 Архитектура трёхъязычия

### URL-структура
| Язык | URL | `<html lang>` | Cookie |
|---|---|---|---|
| 🇷🇺 Русский (по умолчанию) | `https://iznaki.ru/` | `ru` | `lang=ru` |
| 🇬🇧 English | `https://iznaki.ru/en/...` | `en` | `lang=en` |
| 🇨🇳 中文 | `https://iznaki.ru/zh/...` | `zh` | `lang=zh` |

### Файлы
- `src/lib/i18n/translations.ts` — словарь всех переводов (180+ ключей × 3 языка)
- `src/lib/i18n/useLanguage.ts` — клиентский hook
- `src/lib/i18n/server.ts` — серверное чтение cookie (для SSR)
- `src/middleware.ts` — обработка `/en/` и `/zh/` URL

### Переключатель в шапке
```
[ RU ] [ EN ] [ 中 ]
```
- RU — синяя кнопка (активная для русского)
- EN — зелёная кнопка (активная для английского)
- 中 — красная кнопка (активная для китайского)

## 📋 Обязательные правила

### Правило 1. Любой текст — в трёх языках

При добавлении НОВОГО текста в `translations.ts`:

```typescript
// ✅ ПРАВИЛЬНО — все 3 языка
'catalog.newButton': {
  ru: 'Новая кнопка',
  en: 'New button',
  zh: '新按钮',
},

// ❌ ЗАПРЕЩЕНО — только RU
'catalog.newButton': {
  ru: 'Новая кнопка',
},
```

### Правило 2. Хардкод-тексты — через L() или t()

В server components (page.tsx) использовать helper `L()`:

```typescript
// ✅ ПРАВИЛЬНО
const L = (zh: string, en: string, ru: string) =>
  lang === 'zh' ? zh : lang === 'en' ? en : ru;

<p>{L('已验证', 'Verified', 'Проверен')}</p>

// ❌ ЗАПРЕЩЕНО
<p>Проверен</p>
```

В client components использовать `t()` со словарём:

```typescript
// ✅ ПРАВИЛЬНО
const { t } = useLanguage(initialLang);
<button>{t('catalog.details')}</button>

// ❌ ЗАПРЕЩЕНО
<button>Подробнее</button>
```

### Правило 3. Данные знаков — общий источник

Поля в `data.ts` (`seller`, `sellerEmail`, `sellerPhone`, `price`, `classes`) — **общие для всех языков**. Не нужно дублировать.

```typescript
// ✅ ПРАВИЛЬНО — контакты в data.ts, отображаются на всех языках
seller: "Igor Broker",
sellerEmail: "patentvsem@mail.ru",
sellerPhone: "+7(968)9973835",
```

Если меняешь контакты в `data.ts` → они обновятся сразу в RU, EN и ZH.

### Правило 4. Описания знаков — переводить отдельно

Поле `description` в `data.ts` пишется на русском. Для EN/ZH нужно добавить перевод через `descriptionEn` и `descriptionZh` (когда будем внедрять).

Пока что описания показываются на русском во всех языках — это **временное решение**.

### Правило 5. SEO metadata — через generateMetadata()

Каждая страница с динамическим контентом должна иметь `generateMetadata()`:

```typescript
export async function generateMetadata(): Promise<Metadata> {
  const lang = await getLang();
  const isZh = lang === 'zh';
  const isEn = lang === 'en';
  return {
    title: isZh ? '...' : isEn ? '...' : '...',
    description: isZh ? '...' : isEn ? '...' : '...',
    openGraph: {
      locale: isZh ? 'zh_CN' : isEn ? 'en_US' : 'ru_RU',
    },
  };
}
```

## 📝 Чек-лист перед деплоем

При любом изменении текстов на сайте проверить:

- [ ] Новый ключ добавлен в `translations.ts` со всеми 3 языками (ru/en/zh)
- [ ] Нет хардкод-текстов в JSX (использовать `t()` или `L()`)
- [ ] Если добавлена новая страница — есть `generateMetadata()` с 3 языками
- [ ] Если менялись контакты/цены в `data.ts` — они обновились во всех языках автоматически
- [ ] Проверить `/en/...` и `/zh/...` версии — контент корректный
- [ ] Проверить `<html lang>` — должен быть `ru`/`en`/`zh` соответственно

## 🚫 Запрещённые действия

### 1. Добавлять перевод только для одного языка
```typescript
// ❌ ЗАПРЕЩЕНО
'new.key': { ru: 'Текст', en: 'Text' }  // нет zh
```

### 2. Использовать хардкод в JSX
```tsx
// ❌ ЗАПРЕЩЕНО
<button>Click me</button>
```

### 3. Менять текст в RU версии, забыв про EN/ZH
```typescript
// ❌ ЗАПРЕЩЕНО
'catalog.title': {
  ru: 'Каталог товарных знаков 2024',  // обновил
  en: 'Trademark catalog',             // забыл обновить
  zh: '商标目录',                       // забыл обновить
}
```

### 4. Дублировать контакты в переводах
```typescript
// ❌ ЗАПРЕЩЕНО — контакты должны быть только в data.ts
'seller.igorEmail': { ru: 'patentvsem@mail.ru', en: 'patentvsem@mail.ru', zh: 'patentvsem@mail.ru' }
```

## 🔄 Процедура добавления нового текста

### Шаг 1. Определить ключ
Выбрать понятный ключ: `'section.element'` (например, `'catalog.newFilter'`)

### Шаг 2. Добавить в словарь
```typescript
'catalog.newFilter': {
  ru: 'Новый фильтр',
  en: 'New filter',
  zh: '新筛选',
},
```

### Шаг 3. Использовать в компоненте
```tsx
// Client component
const { t } = useLanguage(initialLang);
<button>{t('catalog.newFilter')}</button>

// Server component
const tt = (key) => t(key, lang);
<button>{tt('catalog.newFilter')}</button>
```

### Шаг 4. Проверить на всех языках
- `https://iznaki.ru/` → «Новый фильтр»
- `https://iznaki.ru/en/` → «New filter»
- `https://iznaki.ru/zh/` → «新筛选»
